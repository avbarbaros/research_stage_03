You write short Python programs that answer a question about an image. Use only the API below and plain Python. Do not import anything.

class ImagePatch:
    """A rectangular region of the image.
    Coordinates are pixels of the FULL image: x grows to the right, y grows DOWNWARD (y = 0 is the top edge).
    So a smaller center_y means higher in the image, and a smaller center_x means further left."""
    left, top, right, bottom: int      # box of this patch in full-image pixels
    width, height: int
    center_x, center_y: float
    image_width, image_height: int     # size of the full image
    score: float                       # detector confidence (1.0 for the full image)

    def find(self, object_name: str) -> list[ImagePatch]:
        """All detected instances of object_name inside this patch, most confident first. [] if none.
        object_name is a short noun phrase such as "cup" or "red car"."""
    def exists(self, object_name: str) -> bool:
        """True if find(object_name) is not empty."""
    def count(self, object_name: str) -> int:
        """Number of detected instances of object_name inside this patch."""
    def simple_query(self, question: str) -> str:
        """Ask a vision-language model a simple question about this patch only. Returns a short answer."""
    def verify_property(self, object_name: str, attribute: str) -> bool:
        """True if the object_name shown in this patch has the attribute, e.g. ("shirt", "blue")."""
    def best_text_match(self, options: list[str]) -> str:
        """The option that best describes this patch."""
    def compute_depth(self) -> float:
        """Median distance of this patch from the camera: 0.0 = closest point in the image, 1.0 = farthest."""
    def crop(self, left, top, right, bottom) -> ImagePatch:
        """A new patch for the given full-image box."""
    def overlaps(self, other: ImagePatch) -> bool:
        """True if the two boxes overlap."""

def distance(a: ImagePatch, b: ImagePatch) -> float:
    """Pixel distance between the centres of two patches (in the image plane)."""
def distance_3d(a: ImagePatch, b: ImagePatch) -> float:
    """Approximate distance between two objects in the real scene (image position and depth combined)."""
def bool_to_yesno(b: bool) -> str:
    """"yes" or "no"."""

Rules:
- Write exactly one function `def execute_command(image) -> str:` whose first line is `image_patch = ImagePatch(image)`. It must return the final answer as a string.
- If the question lists options, return one of the options exactly as written.
- Otherwise return a single word or short phrase, for example "yes", "no", "left", "red", "man".
- Use find() and box geometry for left/right, above/below and counting questions. Use compute_depth() for closer/farther-from-the-camera questions. Use simple_query() on a found patch for attributes, materials, actions and names.
- Use distance_3d() for "which object is closer to X" questions about distances between objects; use compute_depth() only for distance to the camera.
- find() returns a list. Check that it is not empty, then use an element such as objects[0]. Never call ImagePatch methods on the list itself.
- When find() returns [] for an object you need, fall back to image_patch.simple_query(<the original question>).
- verify_property() needs a concrete value such as "red", "wooden" or "open", never a property name such as "color". To compare an attribute of two objects, ask simple_query() about each one and compare the answers.
- For open questions, never invent a list of candidate answers; ask simple_query() on the relevant patch instead.
- Every path through the program must return a string. If the question lists options, never return anything that is not one of them.
- Output only the program in one ```python block.

Question: Is there a cat to the left of the sofa?
Answer format: a single word or phrase
```python
def execute_command(image):
    image_patch = ImagePatch(image)
    cats = image_patch.find("cat")
    sofas = image_patch.find("sofa")
    if not cats or not sofas:
        return image_patch.simple_query("Is there a cat to the left of the sofa?")
    sofa = sofas[0]
    for cat in cats:
        if cat.center_x < sofa.center_x:
            return "yes"
    return "no"
```

Question: What color is the car that is next to the tree?
Answer format: a single word or phrase
```python
def execute_command(image):
    image_patch = ImagePatch(image)
    cars = image_patch.find("car")
    if not cars:
        return image_patch.simple_query("What color is the car that is next to the tree?")
    trees = image_patch.find("tree")
    if trees:
        cars = sorted(cars, key=lambda car: distance(car, trees[0]))
    return cars[0].simple_query("What color is this car?")
```
